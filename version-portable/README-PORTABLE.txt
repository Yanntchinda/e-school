 e-School - VERSION PORTABLE
========================================================================

AUCUNE INSTALLATION NÉCESSAIRE !

 Comment lancer l'application :
1. Double-cliquez simplement sur le fichier : LANCER-E-SCHOOL.bat
2. L'application s'ouvre automatiquement dans votre navigateur par défaut
3. Laissez la petite fenêtre noire ouverte pendant que vous utilisez l'application
4. Pour fermer l'application, fermez la fenêtre noire ou double-cliquez sur ARRETER-E-SCHOOL.bat

 Prérequis :
- Python doit être installé sur l'ordinateur (99% des ordinateurs Windows l'ont déjà)
- Si Python n'est pas installé, téléchargez-le gratuitement sur https://www.python.org/
 PENDANT L'INSTALLATION, COCHEZ LA CASE "Add Python to PATH"

 Sauvegarde des données :
Vos classes, élèves, notes et bulletins sont enregistrés AUTOMATIQUEMENT sur votre ordinateur.
Pensez à faire des sauvegardes régulièrement depuis le menu Paramètres > Exporter sauvegarde.

 Vous pouvez copier ce dossier entier sur une clé USB pour utiliser l'application sur n'importe quel ordinateur.
